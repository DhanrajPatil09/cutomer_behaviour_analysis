# Customer Shopping Behaviour Analysis

## Project Overview
This project analyzes customer shopping behaviour to identify purchasing patterns, customer preferences, and business insights that can support data-driven decision-making.

## Tools & Technologies
- **Python:** Data cleaning, exploratory data analysis (EDA), and analysis
- **SQL:** Data querying and customer behaviour analysis
- **Power BI:** Interactive dashboard and data visualization
- **Jupyter Notebook:** Analysis workflow
- **Excel/CSV:** Dataset handling

## Project Files
- `Customer_Shopping_Behavior_Analysis.ipynb` — Python analysis
- `Customer_Behaviour.sql` — SQL queries
- `customer_shopping_behavior.csv` — Dataset
- `customer_behavior_dashboard.pbix` — Power BI dashboard
- `Customer_Shopping_Behavior_Analysis_Report.pdf` — Analysis report
- `Customer-Shopping-Behavior-Analysis-Presentation.pptx` — Project presentation
- `Business_Problem_Document.pdf` — Business problem definition

## Project Objectives
- Understand customer shopping patterns.
- Analyze purchasing behaviour using SQL and Python.
- Identify useful trends and customer insights.
- Present findings through an interactive Power BI dashboard.
- Support business decisions with data-driven insights.

## How to Explore the Project
1. Open the Jupyter Notebook to review the Python analysis.
2. Open the SQL file to explore the queries.
3. Open the Power BI file using Microsoft Power BI Desktop.
4. Read the report and presentation for findings and recommendations.
